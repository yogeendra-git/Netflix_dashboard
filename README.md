# 🎬 Netflix Analytics Dashboard

An interactive and visually engaging Netflix Analytics Dashboard built using **Power BI** to explore
trends, genres, ratings, countries, and content distribution across Netflix titles.

# Project Overview

This dashboard provides deep insights into Netflix's content library using powerful visualizations and interactive filters.  
The project focuses on analyzing:

- Movies vs TV Shows
- Top Genres
- Top Directors
- Titles Added Over the Years
- Country-wise Content Distribution
- Ratings Analysis
- Monthly Content Trends

The dashboard is designed with a Netflix-inspired dark red theme for a professional and cinematic user experience.

# Dashboard Features

## KPI Cards
- Total Titles
- Total Movies
- Total TV Shows

## Interactive Filters
Users can dynamically filter data using:
- Country
- Genre
- Year
- Director

## Visual Analytics
### Movies vs TV Shows
Compare the distribution of movies and TV shows.

### Top Directors
Identify directors with the highest number of titles.

### Top Genres
Analyze the most popular genres on Netflix.

### Titles Added by Year
Track Netflix content growth over time.

### Titles Added by Month
Understand monthly content addition trends.

### Rating Group Analysis
Compare ratings between movies and TV shows.

### Country-wise Analysis
Explore content contribution by country.

### Movie Details Table
Detailed table including:
- Title
- Duration
- Release Year
- Rating

# 📈 Key Insights

- Movies dominate Netflix content compared to TV Shows.
- Significant growth in titles added after 2015.
- Certain genres consistently lead in content volume.
- A small number of directors contribute large amounts of content.
- Content distribution varies significantly by country.
